# 茂迪 Motech｜太陽能發電原理介紹頁

現代簡約風、響應式設計（RWD）的單一 `index.html` 網頁，內容包括：

- 茂迪公司介紹與發展歷程（1981 年成立、1997 年成立光電事業部、2002 年電力事業部、2017 年 3.6 GW 產能里程碑）
- 太陽能發電原理詳解：光子、PN 接面與光伏效應、直流轉交流、完整發電系統
- 互動 PN 接面示意動畫、發電量試算器、PERC / TOPCon / TBC 技術比較、常見問題

本頁為介紹與教育用途的示範網頁，非茂迪官方網站，產品規格以官方資訊為準。
